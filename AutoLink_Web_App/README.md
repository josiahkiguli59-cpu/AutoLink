# AutoLink — New & Used Car Sales Web App

A responsive automotive sales website based on the supplied dark/navy + gold UI reference.

## Sales-focused changes
- All rental language changed to vehicle sales / buying language
- New and used inventory
- Vehicle year, mileage, condition, transmission and asking price
- New/used/SUV/MPV filtering
- Budget and model-year search
- Vehicle enquiry / viewing request modal
- WhatsApp enquiry handoff
- Buyer testimonials
- Inspection, trade-in, financing and after-sale information
- Responsive mobile layout

## Vehicles represented from the supplied UI
- Toyota Avanza
- Toyota Innova Reborn
- Toyota Fortuner
- Mitsubishi Xpander

Additional inventory examples are included to make the catalogue feel like a real dealership.

## Images
The visual direction follows the supplied UI and automotive inspiration commonly found on Pinterest. The site does not scrape or hotlink Pinterest pins directly; instead it uses accessible automotive imagery and links to Pinterest inspiration. This is safer for a production site because individual Pinterest pins may have third-party copyright restrictions.
